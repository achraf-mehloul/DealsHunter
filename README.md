## 🌟 نظرة عامة

Amazon Bot هو نظام متكامل يسمح للمستخدمين بالبحث عن منتجات أمازون عبر بوت تليجرام، مع توفير لوحة تحكم إدارية متقدمة لإدارة النظام.

### 🏗️ المكونات الرئيسية

| المكون | الوصف |
|--------|--------|
| **🤖 Telegram Bot** | بوت ذكي للبحث عن المنتجات وعرضها |
| **📊 Admin Dashboard** | لوحة تحكم لإدارة المستخدمين والمنتجات |
| **🔗 API Gateway** | واجهة برمجة التطبيقات الموحدة |
| **🗄️ Database** | قاعدة بيانات لتخزين المعلومات |
| **⚡ Cache** | نظام تخزين مؤقت لتحسين الأداء |

## 💡 المميزات

### 🔍 البحث المتقدم
- بحث حي في منتجات أمازون
- فلاتر متقدمة (سعر، تقييم، فئة)
- نتائج محدثة باستمرار

### ⭐ المفضلة الذكية
- حفظ المنتجات المفضلة
- متابعة تغيرات الأسعار
- توصيات مخصصة

### 🔔 الإشعارات الذكية
- تنبيهات انخفاض الأسعار
- منتجات جديدة تناسب اهتماماتك
- إشعارات مخصصة

### 📊 التحليلات المتقدمة
- إحصائيات استخدام المستخدمين
- تقارير أداء النظام
- رسوم بيانية تفاعلية
